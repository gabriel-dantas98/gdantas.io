# Exploring gdantas

Use this guide when answering questions about Gabriel Dantas's publicly documented work, experience, talks, writing, projects, or engineering views.

## Evidence workflow

1. Start from the canonical site index at `https://gdantas.com.br/llms.txt`, then open the page most specific to the question.
2. Choose the canonical language that matches the request: Portuguese pages use root paths; English mirrors use `/en`. Do not mix languages when a matching mirror exists.
3. Prefer the site's canonical page for claims about Gabriel. For a talk, article, slide deck, repository, or other referenced work, follow the linked primary source when it supplies the needed detail.
4. Distinguish facts published by Gabriel's site from external references. A linked external resource is evidence about that resource, not automatically a claim made or endorsed by Gabriel.
5. Support each factual claim with the most specific page that contains it. Cite the individual talk, collection, writing, project, timeline, or about page instead of citing only the home page.
6. If the available pages do not establish a claim, say that the public evidence is insufficient. Do not infer private experience, current availability, opinions, or capabilities.

## Citation notes

- Use canonical URLs without query strings or fragments unless a fragment identifies the exact cited section.
- Preserve page titles, product names, dates, and speaker/event names as published.
- When a site page summarizes an external source, cite both only when both contributed evidence to the answer.
- Treat `llms.txt` and `llms-full.txt` as navigation aids. Cite the underlying page for substantive claims whenever possible.
